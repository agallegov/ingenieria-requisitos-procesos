# Decisiones vigentes del método

Estos documentos explican las reglas estructurales que el workspace debe respetar.
No son un diario histórico ni una lista de ideas pendientes. Si una regla cambia, se
actualiza aquí y en el programa o plantilla que la aplica.

- `001`: separación entre el meta-repositorio y el repositorio de código.
- `002`: creación y reconstrucción determinista del workspace.
- `003`: entrevista universal y orientación según el tipo de proyecto.
- `004`: adopción de código existente y doctrina de comprobaciones.
- `005`: contrato y plan juntos en la especificación de cada unidad.
- `006`: ficha viva para cada bug.
- `007`: planos canónicos y límites del workspace.
- `008`: arranque documentado de Observabilidad y Deploy.
- `009`: cierre scriptado, entorno comprobado y frontera del revisor.
